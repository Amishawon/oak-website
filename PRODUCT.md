# Oak website and standalone CMS

Oak Counseling Services' existing branding, copy, routes, images and content collections are retained. The public website is React/Vite. The custom editor at /admin/ uses a standalone PHP API and server-side file storage on cPanel; WordPress is not required. Clinical records and appointment submissions are outside this CMS's scope.

Editors edit drafts, preview authenticated draft content, and explicitly publish. Only published, approved records appear publicly; testimonials also require consent. Existing imported content starts as drafts. A visual redesign should follow the supplied Therapy by Grace reference once that reference can be viewed; it was unavailable during implementation.
